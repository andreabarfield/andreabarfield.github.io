Ames Housing Price Predictor

Turning property characteristics into an estimated sale price with an interactive Streamlit application powered by a Random Forest model.

Python Pandas Random Forest Feature Selection Streamlit Model Evaluation

Project overview

This project developed a house-price prediction application for the Ames, Iowa community using historical home-sales data. Users provide property characteristics such as quality, size, age, basement, and garage features. The application converts those selections into the encoded inputs expected by a trained Random Forest model and returns an estimated sale price.

The goal was to make the model easier to use by reducing the number of required inputs while preserving as much predictive performance as possible.

Model selection

Three Random Forest feature sets were evaluated using the same held-out test split. The 20-feature model was selected for the application because it substantially reduced the number of inputs compared with the original model while retaining similar performance.

Process and reflection

The project followed the CRISP-DM process: business understanding, data understanding, data preparation, modeling, evaluation, and deployment. Comparing multiple feature sets reinforced the importance of evaluating trade-offs rather than choosing a model based on a single metric.

Next steps

Future improvements include testing the model with newer housing data, assessing performance as market conditions change, adding input validation, incorporating user feedback, and monitoring the model for potential retraining needs. The application would also need to be deployed online for public use.
